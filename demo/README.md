# FitPP — демонстрационная версия

Откройте `fitpp-demo-v3.html` двойным щелчком в современном браузере. Сервер, npm и интернет не нужны: стили и Alpine.js включены в HTML.

Это отдельная копия интерфейса из `feat/mobile-emerald-design`. Все имена, посещения и финансовые показатели вымышлены. Начальная дата — 17 октября 2026 года. Доступны журнал, клиенты, карточки, история, финансы, переключение дат и локаций, отметки посещений, редактирование клиентов и продажа демонстрационных абонементов.

Изменения существуют только в памяти вкладки. Кнопка «Сбросить» или перезагрузка восстанавливает пример. Авторизации и Firebase SDK нет; CSP запрещает сетевые соединения, workers и отправку форм. Демо не подключается к рабочей базе. Из-за использования выражений Alpine CSP разрешает выполнение встроенных скриптов и выражений; открывайте неизменённый файл из этой ветки.

При желании можно запустить только эту папку:

```sh
python3 -m http.server 8001 --bind 127.0.0.1 --directory demo
```

Рабочий `index.html`, ветка `main` и Pull Request #1 не изменяются.

Встроенные зависимости: Alpine.js 3.15.12 (MIT), CSS сгенерирован Tailwind CSS 3.4.19 (MIT). Лицензии прилагаются в `THIRD_PARTY_LICENSES.txt`.


Проверка для разработчика: установите Python Playwright и Chromium, затем выполните `python3 demo/test_demo.py`. Тест запускает автономный документ без интернета, проверяет отсутствие внешних запросов, ограничения CSP, основные действия и четыре размера экрана. Изображения сохраняются во временную папку.
