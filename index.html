Заморозка абонемента

Начало сегодня.

Сегодня уже есть посещение или списание. Предлагаем начать заморозку завтра. Сегодняшняя отметка сохранится.

Возвращение — первый активный день; этот день в заморозку не входит.

Остаток занятий сохраняется. Срок продлевается до возвращения; при досрочной разморозке пересчитывается.

Удалить клиента навсегда?

Будет удалена только карточка клиента без абонементов и посещений. Отменить сохранённое удаление нельзя.

Нет действующего подходящего абонемента

Можно оформить абонемент «Заря» или «Поле чудес». Оба действуют на всех локациях: «Заря», «Поле чудес» и «Онлайн».

С какого абонемента списать занятие?

Подходит несколько абонементов. Спишется одно занятие, без новой оплаты.

Продажа абонемента

Дата продажи — дата получения денег. Для истории выберите прошлую дату. Вносите покупки клиента по порядку дат. Недоплата не сохраняется.
